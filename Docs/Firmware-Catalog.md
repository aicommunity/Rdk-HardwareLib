# Firmware Catalog

## RU

Записи в `Catalog/firmwares/*.json` (tier A/B/C/D, `transport`, `available`, `compatibleShields`, `hex`, `hostPlugin`).

Legacy `Firmware/manifest.json` генерируется из catalog скриптом `sync_hardware_catalog.py`.

Env: `RDK_HARDWARE_CATALOG_DIR`, `RDK_HARDWARE_FIRMWARE_DIR`, `NMSDK_SOURCE_DIR`.

## EN

Firmware entries live under `Catalog/firmwares/`; legacy manifest is generated by sync script.
